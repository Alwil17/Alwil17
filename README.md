## What I'm working on

**[Mr Wallet](https://www.mister-wallet.com)** is a personal finance app used by about 200 people. It is free, ad-free and open source ([AGPL-3.0](https://github.com/Grey-Workers-Togo/mr-wallet)). You bring your accounts together, import statements (CSV/Excel), track budgets and debts, forecast cash flow, and every action lands in a timestamped audit log. Built with Next.js, NestJS and PostgreSQL in a TypeScript monorepo, designed and developed with AI assistants. A mobile app (Expo, offline-first) and a conversational AI financial assistant are in progress.

## How I work

- **Backend first.** APIs in FastAPI, NestJS and Spring Boot, with Next.js, React or Angular on the front.
- **Data and platform.** Spark pipelines over 100 million records a day, real-time dashboards (Grafana, ELK), SSO with Keycloak and CI/CD on GitHub Actions.
- **AI in the loop.** Claude Code, GitHub Copilot and Cursor every day, plus LLM integration (structured extraction, prompt engineering, API orchestration), with architecture, tests and code review kept in my hands.
